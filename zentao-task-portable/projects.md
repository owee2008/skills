# 项目与模块查询

用于处理“查看项目列表”“查询某项目模块”“帮我确认模块 ID”等请求。

## 项目列表

```bash
./scripts/zentao-list-projects.py
./scripts/zentao-list-projects.py --user-text "在科技部门禅道"
```

输出应重点展示：

- 项目 ID
- 项目名称
- 代号或状态（如果脚本返回）
- 用户后续创建任务时应使用的项目 ID

## 模块列表

```bash
./scripts/zentao-list-modules.py <项目ID>
./scripts/zentao-list-modules.py <项目ID> --user-text "在田一部门禅道"
```

创建或修改任务模块前必须执行或等效获取完整模块列表，并向用户展示可选模块。即使使用 `modules.yaml` 做关键词推荐，也必须把完整模块列表作为最终选择依据。

## 模块选择规则

1. 优先选择最底层模块；一般不要把普通任务创建在一级模块。
2. 可以根据任务标题和 `modules.yaml` 推荐候选模块，但推荐项只能辅助用户选择。
3. 用户已明确给出模块 ID 时，可以直接使用，但仍建议验证该 ID 属于目标项目。
4. 项目没有模块时，明确说明“该项目没有配置模块”，获得用户同意后使用模块 `0`。

## 常用模块数据库

`modules.yaml` 记录了部分常用项目模块和关键词映射。它只能作为离线参考，不能替代实时模块列表。禅道里的模块可能变更，创建前以脚本查询结果为准。
