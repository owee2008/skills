# 我的日志「通话卡片/通话相关」批量建禅道任务映射参考

用于用户先在 `teamlog` 中新增「我的日志项目」通话卡片/通话相关事项，随后说“创建禅道任务”，但本地参与行仍是 `待确认` 的场景。

## 稳定做法

1. 不要直接按本地 `待确认` 行创建；先实时查询目标禅道项目模块，并校验负责人是否出现在该项目创建页 `assignedTo[]` 下拉。
2. “我的日志项目”通常不是禅道真实项目名：
   - 田一禅道：项目「我的日志」`1681`。
   - 天远/typm 禅道：项目「我的日志2026」`428`。
3. 对跨端通话卡片优化类任务，可先按历史 teamlog 给出推荐映射，但必须让用户确认后再创建。
4. 默认日期按用户偏好：未指定截止日期时使用脚本默认 `T-5` / `T+10`，创建后再读取任务详情回写实际 `estStarted` / `deadline`。

## Presentation requirement

Before creation, show the complete final creation table in a normal chat message (not only in a clarify prompt): 禅道服务、项目/项目ID、模块/模块ID、负责人/账号、任务名、预计工时、剩余工时、开始日期、截止日期、类型。Wait for an explicit “确认创建/开始创建/创建”.
