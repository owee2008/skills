# 真实禅道模块匹配规则

用于把用户提供的任务清单转换为禅道创建清单时的模块选择。

## 核心要求

- 推荐模块必须来自目标禅道项目的真实模块列表，不能根据名称自行编造或沿用未校验的历史模块。
- 优先实时查询目标项目完整模块树，并只在最底层 leaf modules 中做推荐。
- 如果实时查询失败，只能把本地 teamlog / 历史会话中的模块标注为“本地历史已知 / 待校验”，不得把它称为“真实模块”，也不得直接用于创建真实禅道任务。
- 创建任务前，最终模块 ID 必须已经通过实时禅道查询、任务创建页、任务详情或项目模块接口验证。

## 操作流程

1. 明确禅道服务和项目 ID。
   - 天远/科技/typm：`https://typm.tygps.com`
   - 田一/tycd：`https://tycd.tygps.com`
2. 查询项目完整模块列表。
3. 过滤 leaf modules：若某模块路径不是其他模块路径的前缀（`当前路径 + /`），则为 leaf module。
4. 对每条任务：先解释为什么推荐某个真实 leaf 模块，再列出所有真实 leaf 模块供用户选择。
5. 用户确认后，使用该真实模块 ID 创建任务。
6. 创建后读取任务详情验证模块 ID、负责人、预计工时、剩余工时、预计开始日期和截止日期。

## 表述规范

- 可以说：“根据实时查询到的项目模块，推荐 `/语音沟通/视频会议`（ID: 2948）。”
- 不要说：“我猜这个应该放到视频会议模块。”
- 若未实时查到，只能说：“本地历史记录中出现过 `/语音沟通/视频会议`（ID: 2948），但当前未实时校验，需查询后才能创建。”

## 常见错误

- 只根据任务标题猜一个看起来合理的模块。
- 从 teamlog 中抽取历史模块后直接称为真实模块。
- 实时查询失败后仍继续创建。
- 推荐父模块而不是最底层子模块。
